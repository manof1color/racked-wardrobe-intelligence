# Pilot evidence

Redacted written confirmations from pilot brands go here (a pricing acceptance email or signed letter, with personal addresses removed). Add the file path to `evidence` in `data/pilot-status.json`, set the pricing fields, and regenerate the README block; until then no pricing claim is made.

Current status: _victimdesigns and vversatile.usa agreed to join the pilot by phone. Project Qadar agreed by phone and then in writing.

**_victimdesigns** has two filed messages, both Instagram direct messages from the brand's own account (the owner's earlier messages, the status bar and the brand's profile photos are blacked out):

- **Price acceptance, 2026-11-04:** [victimdesigns-pricing-2026-11-04.jpg](victimdesigns-pricing-2026-11-04.jpg). Asked whether it would be open to "$20 for the basic brand plan and $40 for the brand advanced plan", and whether it would commit to one of those price points if the project continued, the brand replied "yeah those prices are fine". That is the price acceptance, and `acceptedOn` in `data/pilot-status.json` stays 2026-11-04.
- **Plan choice, 2026-11-06:** [victimdesigns-plan-choice-2026-11-06.jpg](victimdesigns-plan-choice-2026-11-06.jpg). The owner asked again which plan it would commit to, "the basic plan or the pro plan", and the brand replied "basic". The owner confirms the reply was received on 2026-11-06, in the afternoon; the image shows the owner's follow-up at 9:24 AM but no date for the reply, so the date is the owner's attestation. This is a stated plan choice if the project continues. It is not a signed commitment, and nothing has been paid.

The prices are quoted as written in the messages: $20 and $40. Neither filed message says "a month", so this page does not say the brand agreed to a monthly price. Nothing is billed during the pilot.

vversatile.usa accepted in writing on 2026-11-05 (an iMessage thread with the brand's owner; the contact's name and photo are blacked out, so the image itself does not show the account name: the owner attests it is vversatile.usa): [vversatile-pricing-2026-11-05.jpg](vversatile-pricing-2026-11-05.jpg). The owner also reports a follow-up phone call in which the brand agreed more firmly; there is no recording or written record of the call, so the written thread above remains the filed evidence. Nothing is billed during the pilot.

**Project Qadar** (Instagram: projectqadar) chose the $40 plan in writing on 2026-11-07, in an Instagram direct message from the brand's own account (the status bar is blacked out): [projectqadar-plan-2026-11-07.jpg](projectqadar-plan-2026-11-07.jpg).
