# Contributing

Keep every change easy for judges to follow.

1. Create a focused branch.
2. Make one coherent change.
3. Update the rubric checklist when evidence moves.
4. Run `pnpm lint`, `pnpm test`, and `pnpm build`.
5. Use a descriptive commit such as `feat: add explainable product matching`.
6. Never commit `.env.local`, credentials, PII, copied product images, or unlicensed catalog data.

Recommended checkpoints:

- `chore: establish Next.js competition foundation`
- `feat: add consented consumer wardrobe workflow`
- `feat: add privacy-safe brand matching workspace`
- `test: cover scoring sessions and privacy boundaries`
- `docs: map Racked evidence to competition rubric`
